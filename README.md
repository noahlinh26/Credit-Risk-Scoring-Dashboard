# Credit-Risk-Scoring-Dashboard
Credit risk prediction using Python ML and Power BI visualization:
Làm sạch và tiền xử lý dữ liệu tín dụng bằng Python, bao gồm xử lý dữ liệu thiếu, ngoại lai và mã hóa biến phân loại của gần 32.000 bộ hồ sơ.
Phân tích tỷ lệ nợ xấu theo đặc điểm khách hàng, mục đích vay, xếp hạng khoản vay và lịch sử tín dụng.
Áp dụng và so sánh 3 mô hình phân loại Logistic Regression, Decision Tree và Random Forest, trong đó Random Forest cho kết quả tốt nhất dựa trên Accuracy (93,47%), ROC-AUC (93,7%) và F1-Score (83%).
Phân tích mức độ quan trọng của các yếu tố đối với kết quả dự đoán và trực quan hóa kết quả bằng 4 dashboard trên Power BI.
